# 팀 로고

**사용 허락을 받은 팀의 로고만** 여기에 넣는다. 허락받지 않은 팀은 지금처럼 엠블럼(약칭 + 팀 색)이 나온다.

1. 파일을 이 폴더에 넣는다. 정사각형, 배경이 투명한 PNG 또는 SVG, 256px 이상을 권한다. 파일 이름은 영문 소문자로 (예: `t1.png`, `geng.svg`).
2. `workbench/teams.json`에서 그 팀 항목에 `"logo": "logos/파일이름"`을 더한다.
   예: `"T1": {"short": "T1", "ko": "T1", "c": "#E2012D", "c2": "#111111", "logo": "logos/t1.png"}`
3. 허락받은 기록(메일 등)은 `docs/로고-허락.md`에 팀 이름, 날짜, 허락 범위(어디에 써도 되는지)를 적어 둔다.

공개 칼럼 사이트에는 글에 실제로 쓰인 로고만 복사된다.
